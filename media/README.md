# Материалы рабочего прототипа A-House

Локальные изображения, графика, обложки, логотипы и анимации извлечены из публичных исходников A-House 19 ноября 2026 года. Они сохраняют содержание и кадрирование исходного сайта; изображения-заглушки и сгенерированные замены не использовались. Это материалы исходного проекта, а не заявка на авторство или свободная библиотека для других сайтов.

Охват текущей библиотеки: 26 основных страниц, 62 публикации `/tpost/`, 41 подключённый CSS и список изображений динамических витрин. Карта `.work/media-map.json` сопоставляет 678 исходных абсолютных URL с 493 локальными файлами. Низкокачественные `thb`-миниатюры с тем же идентификатором сопоставлены с полным качественным изображением. Разные мобильные исходники не объединялись по похожести.

418 файлов сохранены побайтово. 75 PNG переведены в WebP без потери пикселей: проверено точное совпадение RGBA, сохранены весь холст, размеры и имеющийся ICC-профиль; ресайз и кроп не применялись. 11 GIF оставлены исходными, вместе с анимацией. Внешних вложенных медиа внутри SVG не обнаружено. Ни один найденный исходник не пришлось заменять из-за ошибки загрузки.

Объём активных медиа: 246 440 261 байт, около 235 МиБ. Самый большой файл — 2 573 189 байт. Открытые WOFF2 и лицензии находятся отдельно в `fonts/`; оригинальные коммерческие шрифты не скопированы. В `.work/media-summary.json` сохранены источник, страницы использования, преобразование, размеры, SHA-256 и результаты проверки каждого материала.

Повторный импорт из обновлённых HTML/CSS:

```sh
python3 tools/import_media.py --workers 6 --python-deps /путь/к/Pillow-fontTools-Brotli --extra .work/services-catalog-assets.txt --prune
```

Параметр `--python-deps` необязателен; без Pillow оптимизация может быть пропущена и исходные файлы сохранятся как есть. `--prune` удаляет только прежние PNG-копии, если они побайтово совпадают с кешированным исходником и уже представлены проверенным WebP; чужие файлы и каталог шрифтов не затрагиваются. Исходные загрузки кешируются во временной папке ОС, вне публикуемой библиотеки.

При добавлении следующей публикации нужно обновить её исходный HTML, запустить импорт и пересобрать страницы по одной карте. Один и тот же исходный URL сохраняет единое локальное соответствие во всех страницах. Новые изображения и неизвестные шрифты должны снова попасть в проверку; неизвестные шрифты импортёр автоматически не публикует.

Проверка библиотеки подтверждает наличие и сохранность материалов. Отсутствие сетевых запросов к Tilda CDN, правильное место изображения в композиции, загрузка ленивых галерей и реальные переносы текста проверяются отдельно на собранных страницах в браузере.
