# Кабинет жюри «Меняя привычное»

Третий этап конкурса МТС и A–House. Член жюри входит по своей учётной записи и может открыть оригиналы 15 работ. Для формы оценивания нужны критерии, шкала и веса из Положения о работе жюри. Пункт 6.2 публичных правил отсылает к этому положению. [Правила конкурса](https://disk.360.yandex.ru/d/kAckYUQ5My6vfg)

## Подготовка файлов и запуск

В закрытую папку на сервере перенесите архив организатора. Команда ниже создаст каталог и перенесёт PDF с сохранением исходных байтов. Имена работ и PDF хранятся в этой папке с доступом у пользователя, который запускает кабинет.

```sh
python3 jury/final/import-materials.py /private/contest/materials.zip /private/contest/final
```

Рядом с `catalogue.json` создайте `members.json` с JSON-массивом идентификаторов разрешённых пользователей из действующего проекта Supabase Auth. Приватную папку подключите к процессу Node.js 20 или новее. Кабинет рассчитан на запуск за HTTPS-прокси на отдельном адресе. Сайт A–House в GitHub Pages собирается своим обычным процессом.

| Переменная | Значение |
| --- | --- |
| `JURY_FINAL_DATA` | Путь к закрытой папке с каталогом, PDF и `members.json` |
| `JURY_ORIGIN` | Полный HTTPS-адрес кабинета без пути |
| `JURY_SUPABASE_URL` | HTTPS-адрес действующего проекта Supabase |
| `JURY_SUPABASE_PUBLISHABLE_KEY` | Публичный ключ `publishable` или `anon` этого проекта |
| `JURY_LOGIN_DOMAIN` | Домен почты, если жюри выданы короткие логины |
| `JURY_HOST`, `JURY_PORT` | Адрес и порт процесса. По умолчанию `127.0.0.1:4183` |

```sh
node jury/final/server.mjs
```

Код публикуется в репозитории. Архив, список аккаунтов и настройки окружения остаются на сервере. Прокси передаёт запросы к кабинету без кэширования. Сервер проверяет допуск для списка, каждой работы и каждого запроса PDF, в том числе при открытии прямой ссылки.

## Локальная проверка

После установки зависимостей A–House и браузеров Playwright запустите проверку с путём к подготовленной папке. Она использует подставные учётные записи и локальный ответ Supabase Auth. Перед рассылкой нужно пройти тот же путь с выданной учётной записью на рабочем адресе и проверить сохранение оценки после повторного входа.

```sh
node jury/final/check.mjs /private/contest/final
```
