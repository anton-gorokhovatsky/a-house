# A–House

[Открыть прототип](https://anton-gorokhovatsky.github.io/a-house/) · [Действующий сайт A–House](https://ahouseproject.com/)

Статическая версия основного сайта для совместной работы с командой. В ней 26 страниц из основной карты сайта и 62 публикации из двух архивных лент. У публикаций сохранены адреса /tpost/ и появился [общий архив](https://anton-gorokhovatsky.github.io/a-house/archive/). Самостоятельные проекты A–News, A–Index, фестиваль и сервис регистрации открываются на своих сайтах.

## Что можно посмотреть

- [Главная](https://anton-gorokhovatsky.github.io/a-house/) — мобильное меню, направления, карточки и оформление A-Friend с ценой и составом полей.
- [Клуб](https://anton-gorokhovatsky.github.io/a-house/club/) — условия трёх уровней участия, фотографии и переход в анкету с выбранным уровнем.
- [Бизнес Москвы](https://anton-gorokhovatsky.github.io/a-house/moscow_business/) — пять карточек программы, материалы встреч и архив из десяти записей.
- [Годовой отчёт](https://anton-gorokhovatsky.github.io/a-house/report/) — раскрывающиеся разделы и фотоматериалы. В старых публикациях работают фотогалереи и возврат в архив.

Формы A-Friend, Member и A-PASS работают в демонстрационном режиме. Они проверяют обязательные поля и дают исправить ответы. Данные живут в открытой форме, демонстрация ничего не отправляет, не списывает деньги и не выдаёт пропуск. Для настоящей операции есть явно подписанный переход на сайт A–House. Ссылки на Timepad, документы и внешние проекты ведут по опубликованным адресам. Исходные страницы старого календаря, дизайна и выставки архитектуры уже недоступны. Для отсутствующих материалов есть страница 404 с выходом на главную и в архив.

## Как запустить

Понадобится Node.js 20 или новее. Установка пакетов для сборки не нужна.

~~~sh
npm run dev
~~~

Локальная версия открывается на [localhost:4173/a-house/](http://localhost:4173/a-house/). После правки исходников выполните npm run build и обновите вкладку. Для сборки под корень своего домена задайте SITE_BASE=/ при запуске.

~~~sh
npm run build
npm run check
~~~

Публикуется только содержимое dist/. GitHub Actions запускает эти же команды после изменения main. У тестового сайта и его страницы 404 в исходном HTML есть robots noindex. Ссылкой можно делиться, авторизация для просмотра не нужна.

## Где редактировать

| Что меняем | Где это находится |
| --- | --- |
| Текст или фотографии раздела | HTML соответствующего раздела в src/pages/. Редакционные публикации лежат в src/pages/tpost/. В src/routes.json указаны заголовок страницы, адрес и её стили. |
| Меню и общие контакты | src/partials/header.html и src/partials/footer.html. Сборка подставляет их на страницы с общей навигацией. |
| Оформление | Общие правила в src/styles/site.css, локальные стили страниц в src/styles/pages/. Исходная сетка и числовые идентификаторы сохранены для совпадения с авторскими макетами. |
| Поведение | src/js/site.js управляет сеткой, меню и архивом. src/js/interactions.js отвечает за галереи, программы, панели и раскрытия, src/js/services.js — за формы и оформление. |
| Фотографии и шрифты | media/. Открытые шрифтовые замены, их происхождение и лицензии описаны в [инструкции к шрифтам](media/fonts/README.md). |

При первой загрузке HTML, JavaScript, стили, фотографии и шрифты приходят с того же хостинга. Встроенное видео обращается к YouTube после выбора посетителя. Для работы прототипа не нужны аккаунт Tilda, её скрипты, CDN или сервер форм.

## Что нужно от команды для боевой версии

| У кого уточнить | Что передать |
| --- | --- |
| Дизайнер или владелец айдентики | Разрешённые веб-файлы и условия размещения Times New Roman VO Condensed, Aperçu Condensed Pro и партнёрских MTS Compact / Extended. Сейчас их роли передают открытые гарнитуры, а фирменный знак используется в исходной графике. |
| Сотрудник, который получает заявки | Куда сегодня приходят Member и A-PASS, как различают уровни клуба, какие согласия и ответы видит участник. Достаточно примера без персональных данных. |
| Ответственный за оплату A-Friend | Кто принимает платёж, как подтверждается успешная оплата и кто выдаёт доступ. Для подключения понадобятся документация сервиса, тестовый магазин или тестовая ссылка и утверждённые оферта и политика. |
| Куратор программы | Ссылки для записи на объявленные встречи, актуальные назначения старых ссылок и материалы, которые можно хранить на хостинге вместо внешнего диска. |
